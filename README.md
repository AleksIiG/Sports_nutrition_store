# 🏋️‍♂️ Sports Nutrition Store

Повноцінний **full-stack вебзастосунок інтернет-магазину спортивного харчування**, розроблений як курсова робота з C# (.NET) з frontend на React.

Проєкт реалізує повний цикл e-commerce системи: **авторизація, ролі користувачів, каталог товарів, кошик, замовлення, адмін-панель та роботу з зображеннями**.

---

## 🚀 Технології

### Backend

* **ASP.NET Core Web API**
* **Entity Framework Core**
* **PostgreSQL**
* **JWT (Access + Refresh tokens)**
* **BCrypt** (хешування паролів)
* **Role-based authorization (User / Admin)**
* **File upload (images)**

### Frontend

* **React**
* **Vite**
* **Axios**
* **React Router**
* **Context API**
* **HTML / CSS (простий, мінімалістичний дизайн)**

---

## 📦 Функціонал

### 👤 Аутентифікація

* Реєстрація користувача
* Вхід / вихід
* Refresh token
* Отримання поточного користувача (`/auth/me`)
* Ролі: **User / Admin**

### 🛒 Товари

* Перегляд списку товарів
* Пошук та фільтрація
* Детальна сторінка товару
* Коментарі до товарів
* Завантаження зображень

### 🧺 Кошик

* Додавання / видалення товарів
* Обмеження по кількості (stock)
* Збереження в `localStorage`

### 📦 Замовлення

* Створення замовлення
* Перегляд замовлень (Admin)
* Зміна статусу замовлення

### 🛠️ Адмін-панель

* CRUD товарів
* CRUD категорій
* Управління замовленнями
* Upload / update зображень
* Автоматичне очищення невикористаних зображень

## 🖼️ Робота з зображеннями

* Зображення зберігаються у `wwwroot/images/products`
* У БД зберігається лише шлях (`ImageUrl`)
* Реалізований сервіс `ImageService`, який:

  * перебирає файли в папці
  * звіряє з БД
  * автоматично видаляє невикористані зображення

## ⚙️ Запуск проєкту

### Backend

1. Налаштувати `appsettings.json`
2. Застосувати міграції

```bash
dotnet ef database update
```

3. Запустити API

```bash
dotnet run
```

Backend працює за адресою:

```
http://localhost:5102
```

### Frontend

```bash
npm install
npm run dev
```

Frontend:

```
http://localhost:5173
```
